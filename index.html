Data Sync -

Data Sync is currently disabled. Data Sync allows you to sync your pull data from this device to another, allowing you to back up your pull data to another device without needing to download/upload backup files.

Data Sync uses WebRTC to facilitate direct browser-to-browser data exchange and it is P2P with no intermediary server involved.

Before activating Data Sync, note the following:

  • In order for devices to find each other, a signalling server is required. The app uses PeerJS Server to act as a signalling server.
  • Due to the above, activating Data Sync will expose your IP address to the signalling server, and the server will retain your IP address for 60 seconds after the last connection attempt.
  • In cases where direct connections are unavailable, Data Sync can fail. Do not rely on the reliability of the Data Sync service
  • Related to the above, Data Sync is not a backup and should not be your only backup source.

Before activating Data Sync, set a peer name. This will appear on other devices.
